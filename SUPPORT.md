# Support

## Contact

For questions, usage assistance, integration problems, or responsible security reports, contact:

**dbrewerton@gmail.com**

Please include:

- a clear description of the issue;
- the affected repository or workflow, when appropriate;
- steps to reproduce the behavior;
- relevant error messages with secrets removed;
- the expected and actual result.

## Security Reports

Do not include access tokens, credentials, private keys, customer information, or other sensitive data in public GitHub issues.

Security-sensitive reports should be sent directly to the support email with the subject:

`Security Report – Beacon Dynamics GitHub Integration`

Reports will be reviewed and handled according to their severity and operational impact.
